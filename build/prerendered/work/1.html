KOPIS 빅데이터 기반 공연 추천 서비스 개발

프로젝트 개요

한국문화정보원의 KOPIS(공연예술통합전산망) 빅데이터를 활용하여 사용자 맞춤형 공연 추천 서비스를 개발했습니다. 공연 데이터와 사용자 선호도를 분석하여 개인화된 추천 시스템을 구현했습니다.

기술 스택

  • Backend: Python, FastAPI
  • Database: PostgreSQL
  • Analytics: Pandas, NumPy, Scikit-learn
  • Frontend: React, TypeScript
  • Infrastructure: Docker, AWS

주요 기능

  1. 실시간 공연 정보 수집 및 분석
  2. 협업 필터링 기반 추천 알고리즘
  3. 사용자 선호도 기반 개인화 추천
  4. 지역별, 장르별 공연 통계 분석
  5. 인터랙티브 데이터 시각화

성과

  • 월간 활성 사용자 5,000명 달성
  • 추천 정확도 85% 이상 달성
  • 공연 예매율 30% 증가
  • 한국문화정보원 우수 활용 사례 선정

기술적 도전과 해결

  • 대용량 공연 데이터 실시간 처리를 위한 최적화
  • 콜드 스타트 문제 해결을 위한 하이브리드 추천 시스템 구현
  • 데이터 품질 개선을 위한 전처리 파이프라인 구축
