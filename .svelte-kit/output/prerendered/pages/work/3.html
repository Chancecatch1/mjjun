얼굴 인식 기반 스마트 도어 시스템

프로젝트 개요

딥러닝 기반의 얼굴 인식 기술과 IoT 기술을 결합하여 안전하고 편리한 스마트 도어 시스템을 개발했습니다. 실시간 얼굴 인식과 함께 모바일 앱을 통한 원격 제어 기능을 제공합니다.

기술 스택

  • 하드웨어: Raspberry Pi 4, Arduino
  • 카메라: Pi Camera Module V2
  • AI/ML: TensorFlow Lite, OpenCV
  • Backend: Python, Flask
  • Frontend: Flutter
  • Database: SQLite
  • 통신: MQTT, WebSocket

주요 기능

  1. 실시간 얼굴 인식 및 출입 관리

    • 딥러닝 기반 얼굴 인식
    • 등록된 사용자 실시간 인증
    • 얼굴 스푸핑 방지 기술 적용

  2. 스마트폰 연동 시스템

    • 실시간 방문자 알림
    • 원격 도어 제어
    • 출입 기록 관리

  3. 보안 기능

    • 이상 행동 감지 및 알림
    • 비상시 원격 잠금
    • 출입 이력 암호화 저장

성과

  • 얼굴 인식 정확도 99.5% 달성
  • 평균 인증 소요 시간 0.5초 이내
  • 보안 사고 발생률 0%
  • 스마트홈 혁신 제품상 수상

기술적 도전과 해결

  • 저조도 환경에서의 인식률 개선
  • 엣지 컴퓨팅 최적화로 처리 속도 향상
  • 배터리 효율성 개선을 위한 전력 관리
  • 네트워크 단절 시 오프라인 동작 구현
