HeartSignal - 실시간 감정 분석 기반 데이트 매칭 서비스

프로젝트 개요

영상 통화 중 사용자의 표정과 음성을 실시간으로 분석하여 상대방과의 호감도를 측정하고, AI 기반으로 최적의 매칭을 제공하는 혁신적인 데이트 매칭 서비스를 개발했습니다.

기술 스택

  • Backend: Node.js, Express
  • Frontend: React Native
  • AI/ML: TensorFlow, OpenCV
  • 실시간 통신: WebRTC, Socket.io
  • Cloud: AWS (EC2, S3, Lambda)
  • Database: MongoDB

주요 기능

  1. 실시간 영상 통화 중 감정 분석
    • 표정 인식을 통한 7가지 기본 감정 분석
    • 음성 톤 분석을 통한 감정 상태 파악
  2. AI 기반 매칭 시스템
    • 사용자 프로필 기반 초기 매칭
    • 실시간 상호작용 데이터 기반 매칭 정확도 향상
  3. 안전한 매칭 환경
    • 실시간 부적절 행동 감지
    • AI 기반 신원 인증 시스템

성과

  • 월간 활성 사용자 10,000명 달성
  • 매칭 성공률 75% 달성
  • 데이팅 앱 시장 내 사용자 만족도 1위
  • 2024년 혁신 기술 스타트업 선정

기술적 도전과 해결

  • 실시간 영상 처리 최적화로 지연 시간 최소화
  • 감정 분석 알고리즘의 정확도 개선
  • 개인정보 보호를 위한 엔드투엔드 암호화 구현
  • 서버 부하 분산을 통한 안정적 서비스 제공
