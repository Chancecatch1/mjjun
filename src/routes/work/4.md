# IoT 기반 스마트팜 프로토타입 개발

## 프로젝트 개요
IoT 센서와 자동화 시스템을 활용하여 작물의 생육 환경을 실시간으로 모니터링하고 제어하는 스마트팜 프로토타입을 개발했습니다. 데이터 기반의 정밀 농업을 실현하여 작물 생산성 향상을 목표로 했습니다.

## 기술 스택
- **하드웨어**: Arduino Mega, 각종 센서 모듈
- **통신**: ESP32, LoRa
- **Backend**: Node.js, Express
- **Frontend**: React.js
- **Database**: InfluxDB (시계열 데이터)
- **모니터링**: Grafana
- **클라우드**: AWS IoT Core

## 주요 기능
1. 환경 모니터링 시스템
   - 온도, 습도, CO2 농도 실시간 측정
   - 토양 수분, pH, EC 레벨 모니터링
   - 일사량 및 광량 측정

2. 자동 제어 시스템
   - 스마트 관수 제어
   - LED 생장광 자동 제어
   - 환기 팬 및 차광막 제어
   - 양액 공급 시스템 제어

3. 데이터 분석 및 예측
   - 생육 환경 데이터 수집 및 분석
   - 작물 생장 예측 모델 개발
   - 최적 생육 조건 도출

## 성과
- 수확량 30% 증가 달성
- 물 사용량 40% 절감
- 에너지 효율 25% 개선
- 농업 혁신 기술 공모전 우수상 수상

## 기술적 도전과 해결
- 센서 네트워크의 안정성 확보
- 저전력 장기 운용을 위한 시스템 최적화
- 실시간 데이터 처리 및 저장 구조 개선
- 원격 모니터링 및 제어 시스템 구현
